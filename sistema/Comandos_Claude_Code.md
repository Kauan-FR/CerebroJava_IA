### Aqui terá comandos uteis do claude code para que possa utilizar na produtividade e nas minhas anotações do Obsidian
#### Caso seja nescessário a revisão do documento procure por [[CLAUDE]]

1. Comando: `revisa <caminho>`
	1. Lê o resumo;
	2. Lê fonte;
	3. Lê páginas relacionadas;
	4. Escreve;

2. Comando: `indexa`
	1. Atualiza o `ìndex.md`

3. Comando: `lint`
	1. Encontra contradições entre páginas;
	2. Conceitos que não tem páginas;
	3. Páginas órfãs;
	4. Resumo sem fonte correspondente;
	5. Resumo que são muitos extensos e redundantes;
	6. Exercícios pendentes parados a mais de 14 dias

4. Comando: `pergunta <dúvida>`
	- Responde perguntas baseando-se na base de conhecimento que já possuo, caso essa base ela não esteja aqui, ele sugere onde encontrar.
