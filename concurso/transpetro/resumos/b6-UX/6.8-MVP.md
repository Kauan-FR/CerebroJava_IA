# Mínimo Produto Viável (MVP) [T-6.8]

## 1. O que é ⭐

Versão do produto com o **menor conjunto de funcionalidades** capaz de ser
**entregue ao usuário real** e gerar **aprendizado validado** sobre a hipótese
de negócio, com o menor esforço.

As três palavras importam:

| Palavra | Significa |
| --- | --- |
| **Mínimo** | O menor escopo possível |
| **Viável** | **Funciona e entrega valor de verdade** — não é rascunho nem peça quebrada |
| **Produto** | Vai às mãos do usuário real, não fica no laboratório |

> [!warning] A pegadinha do "viável"
> Alternativa que define MVP como "versão incompleta, com funcionalidades pela
> metade, para testar internamente" está **errada**. MVP é **pequeno, mas
> funcional e utilizável**.

## 2. Para que serve

Validar a hipótese de negócio **antes** de investir recursos grandes.
Ciclo: **construir → medir → aprender**.

## 3. MVP × protótipo ⭐⭐

> [!danger] Par invertido — MVP × protótipo
> | | **Protótipo** | **MVP** |
> | --- | --- | --- |
> | É usável de verdade? | Não — é simulação | **Sim** — é produto funcionando |
> | Vai para quem | Teste, avaliação interna | **Usuário real, em uso real** |
> | Valida | A **interface/ideia** | A **hipótese de negócio** |
>
> Mnemônico: **protótipo simula, MVP entrega.**

## 4. Tipos de MVP ⭐

| Tipo | Como funciona |
| --- | --- |
| **Concierge** | O usuário sabe que é manual; o serviço é entregue à mão |
| **Mágico de Oz** | O usuário **pensa** que é automatizado, mas há alguém operando por trás |
| **Landing page** | Página com a proposta de valor e um botão, para medir interesse |
| **Protótipo clicável** | Versão navegável (Figma) para testar a experiência |
| **Vídeo demo** | Vídeo demonstrando o produto antes de construí-lo |

> [!danger] Par invertido — concierge × mágico de Oz
> **Concierge: o usuário sabe que é manual.**
> **Mágico de Oz: o usuário não sabe — parece automático.**

## Palavras chave

| Enunciado diz | É |
| --- | --- |
| "menor conjunto de funcionalidades que entrega valor e gera aprendizado" | **MVP** |
| "pequeno, mas funcional e utilizável pelo usuário real" | **MVP** |
| "versão incompleta, só para avaliação interna" | **NÃO** é MVP |
| "construir, medir e aprender" | Ciclo do **MVP** |
| "simula a interface, não é usável de verdade" | **Protótipo** |
| "serviço entregue manualmente, com o usuário ciente" | **Concierge** |
| "parece automatizado, mas é operado manualmente por trás" | **Mágico de Oz** |
| "página com proposta de valor e botão, para medir interesse" | **Landing page** |
