## O que é

MVP (Minimun Viable Product) ou Produto Mínimo Viavel, usado como estrategia para validar ideias de negocios antes de investir grande recursos em desenvolvimento

## Tipos de MVP

- Concierge => Serviço que aparenta ser automatizado para o usuario, mas esta sendo realizado manualmente pelo criador nos bastidores
- Landing Page => Pagian de apresentação com uma proposta de valor clara e um botão de ação para medir o interesse
- Prototipo => Uso de ferramentas como o _Figma_ para criar uma versão clicavel para testar a experiencia do usuario
- Video demo => Um video explicando e demostrando como o sistema ira funcionar antes de ser construido
