## O que é

Comunicar o resultado de uma análise como uma **narrativa**, para que o público
entenda e **tome uma decisão**. Dado sozinho não convence — é a história que
conduz à ação.

> [!warning] O objetivo é a decisão
> Alternativa que define storytelling como "apresentar o maior número possível
> de dados" ou "deixar o público tirar suas conclusões" está **errada**. Há uma
> mensagem clara e uma ação pretendida.

---
## O tripé ⭐⭐

| Elemento | Papel |
| --- | --- |
| **Dados** | A base: métrica certa e confiável |
| **Narrativa** | O contexto e a sequência lógica que dão sentido |
| **Visual** | O gráfico que torna o padrão evidente |

**Dados + narrativa → explica. Dados + visual → esclarece. Narrativa + visual →
envolve. Os três juntos → provocam a mudança.**

---
## Estrutura da narrativa

**Contexto** (a situação) → **conflito** (o problema ou a mudança nos dados) →
**resolução** (o que fazer).

---
## Princípios de visualização ⭐

| Princípio | O que exige |
| --- | --- |
| **Conheça o público** | O que ele precisa decidir muda o que você mostra |
| **Escolha o gráfico certo** | A pergunta define o tipo, não a estética |
| **Elimine o excesso** | Tirar grade, borda, 3D, cor decorativa — tudo que não informa |
| **Dirija a atenção** | Destacar com cor ou tamanho **o que importa** |
| **Conte a história** | Título com a mensagem, não "Vendas por mês" |

> [!danger] Armadilha — gráfico 3D e pizza
> **3D distorce** a percepção e nunca é recomendado.
> **Pizza** só serve para poucas fatias e proporção de um todo; com muitas
> categorias, o **gráfico de barras** é melhor.

---
## Escolha do gráfico ⭐⭐

| Objetivo | Gráfico |
| --- | --- |
| **Evolução no tempo** | **Linha** |
| **Comparação entre categorias** | **Barra / coluna** |
| **Parte do todo (poucas categorias)** | **Pizza** |
| **Relação entre duas variáveis** | **Dispersão (scatter)** |
| **Distribuição de uma variável** | **Histograma** |
| **Um único número em destaque** | **Cartão / indicador** |

> [!danger] Par invertido — histograma × gráfico de barras
> **Histograma = distribuição de uma variável numérica** (faixas contínuas,
> barras coladas).
> **Barras = comparação entre categorias** (barras separadas).

---
## Atributos pré-atentivos ⭐

**Atenção pré-atentiva:** propriedades visuais que o cérebro processa em menos
de 250 ms, **antes** da atenção consciente. É o que faz um elemento "saltar"
sem que a pessoa precise procurar.

**Atributos:** cor · tamanho · posição · orientação · forma · comprimento ·
largura · intensidade · movimento · agrupamento.

> [!warning] Como se usa em dashboard
> Destacar **um** elemento com **um** atributo. Se tudo está destacado,
> nada está destacado.

**As alternativas erradas** (seletiva sequencial, residual, compensatória,
distribuída uniformemente) são **termos inventados** — sinal clássico da
Cesgranrio.

> - **Tinta de dados** — o que representa informação: barras, linhas, pontos,
>   rótulos

>   sombra, fundo colorido, efeito 3D

> carrega informação.
