## O que é

Projetar **como o sistema responde** às ações do usuário: o que ele pode fazer,
como faz e que retorno recebe.

> [!danger] Par invertido — IxD × Arquitetura de Informação
> **IxD (design de interação):** como o usuário **realiza a tarefa** — ações,
> comandos, respostas do sistema.
> **Arquitetura de Informação (AI):** como o conteúdo é **organizado e
> encontrado** — estrutura, categorias, rótulos, navegação, busca.
> Mnemônico: **IxD = fazer. AI = achar.**

---
## Os 4 elementos do IxD

| Elemento | O que define |
| --- | --- |
| **Ações** | O que o usuário pode fazer |
| **Feedback** | O retorno do sistema a cada ação |
| **Estados** | Como a interface se apresenta em cada situação (vazio, carregando, erro) |
| **Fluxo** | A sequência de telas e passos da tarefa |

> [!warning] Feedback é o mais cobrado
> Toda ação precisa de resposta visível. Liga direto com a heurística 1 de
> Nielsen (visibilidade do status).

## 3. Componentes da Arquitetura de Informação ⭐

| Sistema | Função |
| --- | --- |
| **Organização** | Como o conteúdo é agrupado e hierarquizado |
| **Rotulagem** | Os nomes dados a menus, seções e links |
| **Navegação** | Menus, breadcrumb, links — como o usuário se move |
| **Busca** | Como o usuário encontra pelo que procura |

## 4. Conceitos de interação ⭐

| Conceito | O que é |
| --- | --- |
| **Affordance** | A propriedade que **sugere** como usar (botão parece clicável) |
| **Significante** | O sinal que **indica** a affordance (ícone, cor, sublinhado) |
| **Modelo mental** | O que o usuário **acredita** sobre como o sistema funciona |
| **Mapeamento** | Relação clara entre controle e efeito |
| **Restrição** | Limita as ações possíveis para evitar erro |

## 5. Design responsivo × adaptativo ⭐

> [!danger] Par invertido
> **Responsivo:** **um único layout** fluido que se ajusta a qualquer largura
> (grade flexível + media queries).
> **Adaptativo:** **layouts distintos** pré-definidos, um para cada faixa de tela.

**Mobile first:** projeta-se primeiro para a tela menor e depois se amplia.
