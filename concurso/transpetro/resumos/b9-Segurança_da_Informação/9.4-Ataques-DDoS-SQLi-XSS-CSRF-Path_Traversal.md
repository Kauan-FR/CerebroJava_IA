## O que é DDoS

DDoS ou Navegação de Serviço Distribuido tem como objetivo negar serviço enviando malwares atraves de diversos boots que transforma o dispositivo em um zumbi

## O que é SQL injections

Comandos SQL injetados de forma direta nos imputs de senhas e de usuarios ate que o hacker consiga ter acesso ao sistema 

## O que é XSS 

 XSS (Cross-Site Scripting) permite injetar scripts maliciosos atraves do navegador para serem executados pelo usuario

## Tipos de XSS

- Refletido => O script é injetado e executado manualmente, mas não é armazenado permanentemente no servidor
- **Armazenado (Stored):** O script malicioso fica salvo na página e é executado toda vez que um usuário acessa o conteúdo infectado, sendo a forma mais preocupante

## O que é CSRF

CSRF ( Cross Site Request Forgery ) ou Falsificação de Requisição Cruzada entre Sites 

## O que é Path Traversal

Consistem em um erro de programação dos sites da epoca em que o hacker conseguia navegar pelas pastas atraves da barra de endereço do navegador
