## O que é Dados

Correspondecias de um atributos, características, ou propriedade que sozinhos não tem significados
Coleçao de símbolos que dependen de uma estrutura e do contexto nescessário para interpreta-lo e entende-lo

## O que é informação 

Conjunto de dados presentes em um contexto, carregado de significados

## O que é Conhecimento

Propriedade subjetiva ou inerente a quem analisa os dados ou as informações

## O que é inteligencia

Usar o conhecimento para resolver um problema ou resolver problemas novos usando adaptações a este conhecimento
