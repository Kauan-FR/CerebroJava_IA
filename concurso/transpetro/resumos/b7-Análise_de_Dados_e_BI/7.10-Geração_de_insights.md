## O que é insight ⭐

Descoberta **relevante e acionável** extraída dos dados — não é o dado nem o
gráfico, é a **conclusão** que leva a uma decisão.

> [!danger] Par invertido — informação × insight
> **Informação:** "as vendas do Nordeste caíram 15% em setembro."
> **Insight:** "a queda do Nordeste vem da perda de dois clientes grandes que
> migraram para o concorrente após o reajuste."
>
> Informação **descreve**. Insight **explica e aponta ação**.

---
## Os 3 critérios de um bom insight ⭐

| Critério | Pergunta |
| --- | --- |
| **Relevante** | Importa para o objetivo do negócio? |
| **Acionável** | Dá para fazer algo a respeito? |
| **Novo** | Traz algo que não se sabia? |

> [!warning] Acionável é o que mais cai
> Constatação sobre a qual nada pode ser feito não é insight útil.

---
## 3. O caminho até o insight

**Observar** o padrão no dashboard → **questionar** por que ocorre →
**investigar** (drill-down, cruzar dimensões) → **concluir** → **agir**.

Liga com os tipos de análise do 7.2: o insight nasce ao passar da **descritiva**
(o que aconteceu) para a **diagnóstica** (por que aconteceu).

## 4. O que se procura nos dados ⭐

| Padrão | O que é |
| --- | --- |
| **Tendência** | Direção sustentada ao longo do tempo |
| **Sazonalidade** | Variação que se repete em ciclos |
| **Outlier / anomalia** | Valor fora do padrão esperado |
| **Correlação** | Duas variáveis que se movem juntas |
| **Concentração** | Poucos itens respondem pela maior parte (Pareto, 80/20) |

> [!danger] Armadilha — correlação × causalidade
> **Correlação não implica causalidade.** Duas variáveis se moverem juntas não
> prova que uma causa a outra. É a pegadinha mais comum do subtópico.

## 5. Viés de confirmação

Tendência de buscar nos dados apenas o que **confirma** a hipótese que já se
tinha. O analista deve procurar também o que a **contradiz**.
