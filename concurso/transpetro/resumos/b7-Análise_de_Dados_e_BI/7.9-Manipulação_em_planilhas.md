## Referencia Relativa x Absoluta(`$`)

- Relativa => Quando se copia uma formula para outra celula, a referencia muda (`A1` vira `A2`)
- Absoluta => O cifrão (`$`) trava a formula. Não importa para onde você copie a formula, ela sempre apontara exatamente para a celula referete (`$A$1`)
- Mista => O cifrão pode tambem travar apenas a coluna (`$A1`) ou só a linha (`A$1`)

## PROCV / ÍNDICE + CORRESP

- PROCV (Procura Vertical) => Busca uma valor na primeira coluna de uma tabela e retorna m valor na mesma linha, em uma coluna à direita
	- Ex -> - _Sintaxe:_ `=PROCV(valor_procurado; matriz_tabela; núm_índice_coluna; [procurar_intervalo])`. O último argumento deve ser `FALSO` ou `0` para correspondência exata.

- ÍNDICE + CORRESP => O `CORRESP` descobre em que linha/coluna o valor está, e o `ÍNDICE` retorna o valor naquela posição
- OBS => O PROCV **não consegue** procurar valores à esquerda da coluna de busca. O ÍNDICE+CORRESP consegue.

## SOMASE / CONT.SE / SOMASES

- CONTA.SE => Conta quantas celulas atendem a um unico criterio
	- Ex -> contar quantos "Aprivados" existem

- SOMASE => Soma os valores de celulas que atemdem a m unico criterio
- SOMASES / CONT.SES => Versões com S no final permitem multiplos criterios
	- Ex -> somar vendas do "Vendedor X" no "Mês Y"
- OBS => No `SOMASE`, o intervalo a ser somado é o **último** argumento. No `SOMASES`, o intervalo a ser somado é o **primeiro** argumento.

## Tabela Dinamica

Ferramenta que resume, analisa, explora e apresenta volumes de dados sem alterar a tabela original

## Filtro x Classificação

- **Filtro:** **Oculta** as linhas que não atendem ao critério, mostrando apenas o subconjunto de dados desejado.
- **Classificação (Ordenação):** **Reorganiza** a ordem dos dados (ex: A-Z, Z-A, do menor para o maior), mas **todas** as linhas permanecem visíveis.
