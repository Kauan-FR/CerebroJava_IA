## O que é Scrum

Monitoramento e planejamento do projeto o qual esta sendo desenvolvido 

## Os três pilares

|    Pilares    | Descrição                                                             |
| :-----------: | --------------------------------------------------------------------- |
| Transparência | Todos tem conhecimento do projeto e de como esta o andamento dele     |
|   Inspeção    | O tempo todo esta sendo especionado o que esta sendo feito no projeto |
|   Adaptação   | Adaptação, tanto do processo, quanto do produto às mudanças           |

## Pápeis

|    Pápeis     | Descrição                                       |
| :-----------: | ----------------------------------------------- |
| Product Owner | Lider e quem dita como o projeto será feito     |
| Scrum Master  | Responsavel por ajudar a todos entender o Scrum |
|   Dev Team    | O time de desenvolvimento do projeto            |

## O que é KanBan

Um quadro que se divide em três partes, fazendo, validação e concluido
