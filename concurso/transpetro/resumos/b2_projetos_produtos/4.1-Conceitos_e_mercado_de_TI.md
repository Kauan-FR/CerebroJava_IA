## 1. Conceitos, segmentos e mercado de TI (4.1)

### 1.1 Os três termos que a banca troca

| Termo                                          | O que é                                                                                                                        | Escopo                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
| **TI** (Tecnologia da Informação)              | Recursos para **tratar** informação: hardware, software, dados, redes, pessoas                                                 | Mais restrito                |
| **TIC** (Tec. da Informação e **Comunicação**) | TI **+** as tecnologias de comunicação/telecom que transmitem a informação                                                     | Mais amplo                   |
| **SI** (Sistema de Informação)                 | O conjunto organizado (pessoas + processos + TI) que **coleta, processa, armazena e distribui** informação para apoiar decisão | TI é um **componente** do SI |

> [!danger] Par invertido — TI × SI
> SI é o todo; TI é a parte tecnológica dele. **SI existe sem computador**
> (um arquivo de papel bem organizado é um SI). TI, não.
> Mnemônico: **S**I é o **S**istema inteiro. TI é só a **T**ecnologia dentro dele.

### 1.2 Segmentos do mercado de TI ⭐ 

| Segmento | O que inclui |
| --- | --- |
| **Hardware** | Servidores, PCs, dispositivos, periféricos, data center |
| **Software** | Licenças, sistemas, aplicativos, plataformas |
| **Serviços** | Consultoria, integração, suporte, outsourcing, nuvem, segurança |
| **Telecom** | Conectividade, redes, links (entra quando se fala TIC) |

Tendência estrutural: o mercado **migra de hardware/licença para serviço e
assinatura**. Vender caixa vira vender acesso recorrente.

### 1.3 Modelos de entrega (nuvem)

| Modelo | O cliente gerencia | Exemplo |
| --- | --- | --- |
| **IaaS** | SO, middleware, runtime, dados, aplicação | Máquina virtual |
| **PaaS** | Dados e aplicação | Plataforma de deploy |
| **SaaS** | Praticamente nada (só configuração e dados) | E-mail, CRM web |

> [!tip] Mnemônico da escada
> Quanto **mais longe do "I"**, **menos você gerencia**.
> IaaS = você monta. PaaS = você programa. SaaS = você só usa.

### 1.4 Papel da TI na organização ⭐

| Visão | Como a TI é tratada |
| --- | --- |
| **TI como commodity / custo** | Área de suporte, centro de custo, avaliada por corte de despesa |
| **TI como ativo estratégico** | Habilitadora de negócio, gera vantagem competitiva, avaliada por valor entregue |

**TI bimodal** (conceito Gartner): a organização opera dois modos ao mesmo tempo.

| Modo | Foco | Perfil |
| --- | --- | --- |
| **Modo 1** | Previsibilidade, estabilidade, sistemas legados críticos | Cascata, ciclo longo |
| **Modo 2** | Exploração, experimentação, inovação | Ágil, ciclo curto |

**Transformação digital** — não é "comprar tecnologia". É usar tecnologia digital
para **redesenhar modelo de negócio, processos e experiência do cliente**.

> [!warning] Armadilha clássica
> Alternativa que define transformação digital como "informatizar/digitalizar os
> processos existentes" está **errada**. Isso é **digitização/automação**.
> Transformação digital **muda o modelo**, não só o meio.

## Palavras-gatilho

| Enunciado diz                                                      | É                                           |
| ------------------------------------------------------------------ | ------------------------------------------- |
| "ideia nova, ainda sem uso comercial" / "patente não explorada"    | **Invenção**                                |
| "introduzida no mercado" / "gerou valor"                           | **Inovação**                                |
| "processo que destrói o antigo enquanto cria o novo"               | **Destruição criadora** (Schumpeter)        |
| "produto, processo, marketing e organizacional"                    | **Manual de Oslo**                          |
| "pesquisa básica, aplicada e desenvolvimento experimental"         | **Manual de Frascati**                      |
| "melhoria contínua do que já existe"                               | Inovação **incremental**                    |
| "rompe com o padrão, alto risco"                                   | Inovação **radical**                        |
| "desempenho inferior no início, mais barata, cliente não atendido" | Inovação **disruptiva** (Christensen)       |
| "líder de mercado ignora a ameaça ouvindo seus melhores clientes"  | **Dilema do inovador**                      |
| "ideias de fora + licenciar para fora"                             | Inovação **aberta** (Chesbrough)            |
| "inovadores, adotantes iniciais, maioria, retardatários"           | Difusão de **Rogers**                       |
| "lacuna entre adotantes iniciais e maioria inicial"                | **Abismo/chasm** (Moore)                    |
| "expectativa infla, cai e depois estabiliza"                       | **Hype Cycle** (Gartner)                    |
| "desempenho × esforço, satura no fim"                              | **Curva S**                                 |
| "transistores dobram a cada ~18-24 meses"                          | **Lei de Moore**                            |
| "valor da rede cresce com o nº de usuários"                        | **Lei de Metcalfe / externalidade de rede** |
| "consulta a especialistas em rodadas, anônima"                     | **Delphi**                                  |
| "universidade + empresa + governo"                                 | **Tríplice hélice**                         |
| "etapas sequenciais da ciência ao mercado"                         | Modelo **linear** (criticado)               |
| "laços de retorno, inovação pode nascer do mercado"                | Modelo **interativo** (Kline & Rosenberg)   |
| "escala de 1 a 9 de maturidade tecnológica"                        | **TRL**                                     |
| "lacuna de financiamento entre pesquisa e produto"                 | **Vale da morte**                           |
| "incentivo fiscal para P&D no IRPJ"                                | **Lei do Bem** (11.196/2005)                |
| "ICT e NIT"                                                        | **Lei da Inovação** (10.973/2004)           |
| "flexibilizou parcerias ICT-empresa em 2016"                       | **Marco Legal de CT&I** (13.243/2016)       |
| "dois modos de operação de TI, um estável e um exploratório"       | **TI bimodal**                              |
| "redesenho do modelo de negócio com tecnologia digital"            | **Transformação digital**                   |
| "apenas digitalizar processo existente"                            | **NÃO** é transformação digital             |
