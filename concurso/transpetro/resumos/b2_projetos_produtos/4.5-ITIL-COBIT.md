## O que é ITIL

Conjunto de boas praticas, guia com as melhores praticas, diretrizes que as empresas podem adaptar para planejar e dar suporte para os servisos de TI do melhor jeito possivel

## Ciclo de Vida

|   Etapa    | Descrição                                                                     |
| :--------: | ----------------------------------------------------------------------------- |
| Estratégia | Define - Define quais serviços oferecem e para quem                           |
|  Desenho   | Como vai ser - Planeja e projeta o novo serviço                               |
| Transição  | Tira do papel - Constrói, testa e implanta o serviço com segurança            |
|  Operação  | Cuida do dia a dia - Gerencia o serviço dia a dia, garantindo o funcionamento |
|  Melhoria  | Como aprimorar - Mede e aprimora o serviço constantemente                     |

## Praticas essenciais

|          Praticas           | Descrção                                           |
| :-------------------------: | -------------------------------------------------- |
| Gerenciamento de Incidentes | Busca solucionar o problema o mais rapido possivel |
| Gerenciamento de Problemas  | Busca o motivo do problema                         |

## O que é COBIT

Um framework para governança e gestão de TI
O COBIT é uma ponte entre o negócio e tecnologia
Alinha a TI com objetivos estratégicos do negócio garantindo que a tecnologia, crie valor e resultado

## Governança x Gestão

| Governança | O que - Define a direção e monitora para garantir que os objetivos sejam acordados |
| :--------: | ---------------------------------------------------------------------------------- |
|   Gestão   | Como - Planeja, constroi e executa as atividades para alcançar os objetivos        |

## Os 5 dominios

| Dominios | Descrição                                                                                                              |
| :------: | ---------------------------------------------------------------------------------------------------------------------- |
|   EDM    | Coração da governança - Garante que todas as descisões e estrategias estejam alinhadas com os objetivos da organização |
|   APO    | Planejamento Estrategico de TI - Garante que a estrutura e os recursos estejam alinhados ao negocio                    |
|   BAI    | Ciclo de vida - Garante que os projetos de desenvolvimento e aquisição agreguem valor                                  |
|   DSS    | Operações diárias - Garante o suporte tecnico, continuidade de serviço e segurança pra que tudo funcione bem           |
|   MAA    | Auditoria e Desenpelho -  Medi o sucesso das praticas de governança e gestão                                           |
