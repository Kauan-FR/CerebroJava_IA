## O que é ITIL

Conjunto de boas praticas, guia com as melhores praticas, diretrizes que as empresas podem adaptar para planejar e dar suporte para os servisos de TI do melhor jeito possivel

## Ciclo de Vida

|   Etapa    | Descrição                                                                     |
| :--------: | ----------------------------------------------------------------------------- |
| Estratégia | Define - Define quais serviços oferecem e para quem                           |
|  Desenho   | Como vai ser - Planeja e projeta o novo serviço                               |
| Transição  | Tira do papel - Constrói, testa e implanta o serviço com segurança            |
|  Operação  | Cuida do dia a dia - Gerencia o serviço dia a dia, garantindo o funcionamento |
|  Melhoria  | Como aprimorar - Mede e aprimora o serviço constantemente                     |

## Praticas essenciais

|          Praticas           | Descrção                                           |
| :-------------------------: | -------------------------------------------------- |
| Gerenciamento de Incidentes | Busca solucionar o problema o mais rapido possivel |
| Gerenciamento de Problemas  | Busca o motivo do problema                         |
