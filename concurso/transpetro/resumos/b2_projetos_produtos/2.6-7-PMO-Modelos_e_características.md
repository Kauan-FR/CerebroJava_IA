## O que é PMO

Profissional que faz arte do escritorio de projetos

## Função 

Ser o guardião da metodologia, parte de governança, um líder, cuida do portifolio da empresa

## Tipos de PMO

|   Tipos    | Descrição                                                       |
| :--------: | --------------------------------------------------------------- |
| Consultivo | Ajuda o gerente de projetos a encontrar soluções para o projeto |
|  Controle  | Fiscaliza o trabalho do gerente de projeto                      |
|  Diretivo  | Faz a gestão do projeto com o gerente de projeto ou sozinho     |
