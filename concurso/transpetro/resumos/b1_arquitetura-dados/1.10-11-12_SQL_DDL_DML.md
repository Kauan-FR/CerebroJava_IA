## O que é

O SQL ou Structured Query Language (Linguagem de Consulta Estruturada) é a forma de comunicação entre o usuário e o SGBD

## Integridade de dados

Diz que todos os dados armazenados nas tuplas tem que corresponder ao valor do domínio exigido

## CRUD

**`INSERT` =>** Inseri uma nova tupla na coluna
**`SELECT` =>** Seleciona a tupla para ler
**`UPDADE` =>** Atualiza um dado no banco
**`DELETE` =>** Apaga um dado do banco
**`JOIN` =>** Junta tabelas a partir de um valor

## DDL - Linguagem de Definição de Dados

Comandos que interagem com objetos dentro do banco de dados

| Clausula | O que faz                                                     |
| :------: | ------------------------------------------------------------- |
| `CREATE` | Criar uma nova tabela, view ou outros objetos dentro do banco |
| `ALTER`  | Modificar um objeto dentro do banco (tuplas, view, etc)       |
|  `DROP`  | Exclui um objeto do banco (tabela, view, etc)                 |

## DML - Linguagem de manilupação de dados

Comandos que interagem com os dado dentro de tabela

| Clausula | O que faz                                    |
| :------: | -------------------------------------------- |
| `INSERT` | Adiciona uma nova linha na tabela            |
| `UPDADE` | Atualiza os valores das linhas de uma tabela |
| `DELETE` | Exclui linhas de uma tabela                  |

## TCL - Linguagem de controle de transações

São os comandos para controle de transações no SQL

|  Clausula  | O que faz                    |
| :--------: | ---------------------------- |
|  `COMMIT`  | Salva as alterações no banco |
| `ROLLBACK` | Desfaz alterações no banco   |
