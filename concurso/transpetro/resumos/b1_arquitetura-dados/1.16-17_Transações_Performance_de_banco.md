## O que é Transações

Conjunto de uma ou mais operações (como inserções, atualizações ou exclusões)

A regra de ouro é: Tudo ou Nada. Se uma unica operação falhar, todo o conjunto é cancelado e o banco volta ao estado anterior

Para garantir isso, os bancos de dados relacionais seguem as propriedades **ACID**:

Atomicidade => Tudo ou nada
Consistência => O banco sai de um estado valido, e vai para outro estado valido, respeitando as regras e restrições
Isolamento => Todas as operações são executadas de forma isolada, fazendo com que uma não possa interferir na outra
Durabilidade => Uma vez que a transação é confirmada (commit), os dados são salvos permanentemente, mesmo quando a que da de energia

## O que é Performance

Refere-se à capacidade do banco de dados de processar consultas e transações da forma mais rápido possível, consumindo o minimo de recursos
