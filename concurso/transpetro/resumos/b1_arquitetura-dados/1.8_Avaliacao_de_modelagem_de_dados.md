## O que é

É o de analise, validação e teste do modelo de dados antes e durante a sua implementação, para garantir que ela atenda as necessidades do negócio, às limitações técnicas e às regras de governança

## Pilares da avaliação

| Pilar      | Descrição                                                                                                                                          |
| :--------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Negocio    | Analisa se o modelo ele representa corretamente as regras e os processos da empresa, e verifica se as entidades fazem sentido para o usuário final |
| Tecnico    | Analisa se o modelo é performatico e escalavel, se os tipos de dados estão corretos, se a normalização ou desnormalização esta adequada            |
| Governança | Verifica se o modelo respeita o LGPD, se as colunas sensiveis estão identificadas                                                                  |
