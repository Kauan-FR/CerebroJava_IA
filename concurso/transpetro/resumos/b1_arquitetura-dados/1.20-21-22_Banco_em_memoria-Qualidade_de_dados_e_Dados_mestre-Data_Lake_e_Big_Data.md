## O que é Banco em Memória

É um sistema de gerenciamento de banco de dados que armazena e processa os dados principalmente na memória RAM, em vez de depender de disco rígidos tradicionais (HD ou SSD)

## Para que serve

- Velocidade Extrema => O acesso aos dados ocorre em microssegundos ou milissegundos por cota de ser executados na memoria RAM
- Analise em Tempo Real (Real-Time Analytics) => Processar milhões de transações por segundo para tomar decisões imediatas
- Caching e Sessões => Armazenar dados temporários de alta demanda, como o carrilho de compras de um e-commerce ou o placar de um jogo online
- IoT (Internet das Coisas) => Processar o fluxo contínuo e massivo de dados de sensores em tempo real

## O que é Qualidade de dados

De quanto os dados são confiáveis

É importante para garantir que os dados sejam precisos, consistentes e úteis para suportar as decisões de negócio

## O que é Data Lake (Lago de dados)

Repositorio qeu armazena dados brutos, pode ser em JSON, LOGs, CSV, texto ...

Os dados são transformados para analise, o acesso é de forma aberta, sem precisar mover para outro sistema
Exigem governancia e manutençaõ continua, para que os dados possam continuar sendo acessados, sem isso corre o risco de se tornar um pantano de dados
