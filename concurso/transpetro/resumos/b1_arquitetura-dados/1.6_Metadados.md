# 1.6 Metadados

## O que é

**Dados sobre dados** — informação que descreve a estrutura, o significado, a
origem e o uso de outro dado.

| | Exemplo |
| --- | --- |
| **Dado** | `546.695.695-87` |
| **Metadado** | A coluna `cpf` é `VARCHAR(14)`, obrigatória, contém dado pessoal, alimentada pelo sistema de cadastro |

> [!warning] Dado é o conteúdo; metadado descreve o conteúdo

## Três categorias

### Técnicos — como o dado é estruturado

| Item | O que é |
| --- | --- |
| **Dicionário de dados** | Documentação da estrutura: tabelas, colunas, tipos, tamanhos, restrições, relacionamentos |
| **Linhagem de dados** | Rastreia **origem e transformações** — de onde veio, por onde passou, o que mudou |
| **Modelo de dados** | Os modelos conceitual, lógico e físico |
| **Data profiling** | Examina os dados **reais** e coleta estatísticas: nulos, distintos, mínimo/máximo, padrões |

### De negócio — o que o dado significa

| Item | O que é |
| --- | --- |
| **Descrição de tabela** | O que representa, para que serve, quem é o responsável (data owner) |
| **Descrição de coluna** | O que cada atributo significa no negócio |
| **Termos de negócio** | Glossário corporativo — padroniza o vocabulário entre áreas |
| **Classificações** | Marca dados pessoais, sensíveis, confidenciais |
| **Regras de qualidade** | Critérios de validade, completude, consistência |
| **Domínios** | Valores permitidos (ex.: situação ∈ {ATIVO, SUSPENSO, ENCERRADO}) |

### Operacionais — como o dado é usado

Logs de acesso, data e hora de carga, volume processado, sucesso/falha de execução,
quem consultou o quê.

## Catálogo do sistema ⭐

Onde o **SGBD** armazena automaticamente os metadados de tudo que é criado.
Também chamado **dicionário de dados** ou, em SQL padrão, `INFORMATION_SCHEMA`.

Guarda: tabelas, colunas, tipos, índices, restrições, visões, usuários, permissões.

É atualizado sozinho a cada `CREATE`, `ALTER`, `DROP`.

> [!danger] Par que a banca inverte
> | | Guarda | Serve para |
> | --- | --- | --- |
> | **Catálogo / dicionário de dados** | **Metadados** — estrutura | saber **como o banco é estruturado** |
> | **Log de transações** | **Operações** — o que foi alterado, quando, por qual transação | **recuperar** o banco após falha, desfazer transação |
>
> "informações sobre as **estruturas criadas**" → estrutura é metadado → **catálogo**

## Dado pessoal × dado pessoal sensível (LGPD)

| | Definição |
| --- | --- |
| **Dado pessoal** | Informação relacionada a pessoa natural **identificada ou identificável** — nome, CPF, e-mail, IP |
| **Dado pessoal sensível** | Origem racial ou étnica, convicção religiosa, opinião política, filiação a sindicato ou organização religiosa/filosófica/política, dado referente à saúde ou à vida sexual, dado genético ou biométrico |

> [!warning] A lista de sensíveis é **fechada** na LGPD
> Senha, cartão de crédito e credencial de sistema são **confidenciais**,
> mas não são "dados sensíveis" no sentido legal.

Repete no bloco 4 → [[4.6_LGPD_Lei_13.709]]
