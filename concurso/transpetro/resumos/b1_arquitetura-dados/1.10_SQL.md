## O que é

O SQL ou Structured Query Language (Linguagem de Consulta Estruturada) é a forma de comunicação entre o usuário e o SGBD

## Integridade de dados

Diz que todos os dados armazenados nas tuplas tem que corresponder ao valor do domínio exigido

## CRUD

**`INSERT` =>** Inseri uma nova tupla na coluna
**`SELECT` =>** Seleciona a tupla para ler
**`UPDADE` =>** Atualiza um dado no banco
**`DELETE` =>** Apaga um dado do banco
**`JOIN` =>** Junta tabelas a partir de um valor
