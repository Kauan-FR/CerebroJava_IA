## Modelo

Modelo é uma forma de organizar as informações que está na mente cliente, para que o desenvolvedor ele saiba o que tem que ser feito no desenvolvimento do banco

## Modelo de dados

É o processo de modelagem dos dados para um sistema de informação, onde todas as informações do cliente irão se transformar em atributos e colunas na tabela

## Modelo relacional

É uma tabela de banco de dados que conseguem se relacionar entre si.

## Componentes do modelo relacional

Os componentes desse modelo são as relações, os atributos que proporciona esse relacionamento

## Banco de dados relacional

Basicamente são tabelas que armazenam informações, e com isso essas informações são relacionadas

## Componentes do banco de dados relacional

- Tabela => Estrutura onde esta localizado todos os atributos e colunas que formam uma tabela
- Tuplas => São as linhas da tabela, onde estão armazenadas os dados do cliente.
- Colunas => Local onde se armazena um tipo especifico do dado, ou ela também pode não armazenar nada (valores nulos)
- Relacionamento => É a junção de duas tabelas através de dois atributos chamados chave primaria e chave estrangeira
- Outros => Índices, SP, Trigger etc ...
- Chave primaria => Atributo com o valor único que não se repete, muita das vezes gerado automaticamente pelo SGBD
- Chave estrangeira => Atributo derivado da chave primaria e utilizado para relacionar dois ou mais atributos

## Analise de requisitos

Face feita para analizar quais  dados serão armazenados no banco, quais dados serão descartados para não poluir o banco com informações desnecessarias. Essa face ela é extremamente importante para evitar redundancia de dados e o armazenamente de informações inuteis 

## Modelo entidade-relacionamento (MER)

Usado para ilustrar o relacionamento das tabelas, que posteriormente será gerado como um modelo grafico, que será mais simples de visualizar os relacionamentos
