## O que é

Capacidade de alterar a estrutura do banco em um nível **sem afetar o nível
superior** nem as aplicações. É o principal benefício da arquitetura de três
esquemas.

> [!warning] Só existem DUAS
> Física e lógica. "Referencial", "semântica", "transacional" são **distratores**.

## Vínculo com ANSI/SPARC ⭐

A independência nasce da separação em três níveis:

EXTERNO (visões)  
↑ independência LÓGICA  
CONCEITUAL (estrutura lógica)  
↑ independência FÍSICA  
INTERNO (armazenamento físico)


| Independência | Fica entre | Isola mudança em |
| --- | --- | --- |
| **Lógica** | externo ↔ conceitual | estrutura lógica (tabelas, colunas) |
| **Física** | conceitual ↔ interno | armazenamento (índice, partição, disco) |

## Independência física

Mudar **como o dado é guardado**, sem afetar o esquema conceitual nem as aplicações.

Exemplos: criar/remover índice, particionar tabela, mudar de HD para SSD, reorganizar
arquivos, comprimir dados.

**Garantida por:** o próprio SGBD, via mapeamento conceitual-interno.
**Beneficia:** o DBA, que otimiza desempenho sem avisar os desenvolvedores.

> [!warning] Trocar de SGBD NÃO é independência física
> Oracle → PostgreSQL é migração — muda dialeto, tipos, comportamento.
> Física é dentro do mesmo SGBD.

## Independência lógica

Mudar a **estrutura lógica**, sem que as aplicações e visões existentes precisem
ser reescritas.

Exemplos: adicionar uma nova coluna, adicionar uma nova entidade, dividir uma tabela
em duas mantendo uma **view** com a estrutura original.

**Garantida por:** principalmente **views**.
**Beneficia:** desenvolvimento e negócio — o banco evolui sem quebrar os sistemas.

> [!warning] Renomear coluna quebra a aplicação
> Não é bom exemplo de independência lógica. O exemplo certo é **adicionar** algo,
> ou reestruturar por baixo mantendo a view antiga. Ver [[1-02-criacao-alteracao-modelos]]

## A lógica é mais difícil ⭐

> [!danger] Cai na prova e é contraintuitivo
> A independência **lógica é mais difícil de alcançar** que a física.
>
> Motivo: a aplicação depende **diretamente** da estrutura lógica. Isolá-la de uma
> mudança nesse nível exige uma camada de tradução (a view). A mudança física já é
> naturalmente escondida pelo SGBD.

## Palavras-gatilho

| Enunciado diz | É |
| --- | --- |
| "criar índice sem afetar as aplicações" | **física** |
| "particionar / mudar armazenamento" | **física** |
| "adicionar coluna sem reescrever programas" | **lógica** |
| "dividir tabela mantendo o acesso original" | **lógica** (via view) |
| "entre externo e conceitual" | **lógica** |
| "entre conceitual e interno" | **física** |
| "a mais difícil de alcançar" | **lógica** |
| "independência referencial / semântica" | **não existe** — distrator |
