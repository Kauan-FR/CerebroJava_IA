## O que é

Capacidade de alterar a estrutura de armazenamento ou a organização lógica dos dados no banco de dados sem que seja necessário modificar os programas, aplicativos ou relatórios que utilizam esses dados

## Níveis de independência de dados

### Independência Física
- **O que é:** A capacidade de alterar como os dados são armazenados fisicamente (ex: mudar de HD para SSD, criar novos índices, particionar tabelas, alterar o SGBD de Oracle para PostgreSQL) sem afetar o modelo lógico ou os aplicativos
- **Quem se beneficia:** A equipe de DBA/Infraestrutura, que pode otimizar a performance sem avisar os desenvolvedores.
