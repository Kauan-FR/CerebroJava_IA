## O que é

É uma tabela voltada para o conceito de negocios, organizada e pensada pra descrever dados para apresentações, onde teremos uma tabela `fato` no meio que é onde guardamos as metricas, e essa tabela ela esta rodeada por tabelas do tipo `dimensao` onde esta guardado os modelos descritivos

## Conceitos

### Tabela fato

Contem metricas ou medidas quantitativas do negocio. Geralmente possuem FK que referenciam a suas dimensões
Exemplo:
 - numero de vendas, quantida das vendas, lucro das vendas, quantidade de vendas de cada loja

Utilizam FK para se relacionar com as tabelas dimensões que contem as PK, pelo que eu entendi a tabela fato ela funciona como uma tabela associativa

### Tabelas de dimesões

Contem dados descritivos que contextualizam os fatos. Oferecem informações para filtrar, agupar e rotular os dadosnas analises. As tabelas dimensões tendem a ser desnormalizadas para otimizar as consultas
Exemplo:
- tempo, produto, cliente, localização

### Granularidade

Define o nivel de detalhes dos dados nas tabelas fatos. É crucial definir a granularidade mais atômica possivel para permitir analises flexiveis

### Dimensionalidade

São representados pelas diferentes perspectivas ou angulos pelos quais os dados podem ser analisados, fornecidas pelas tabelas dimesões

## Star schema - Esquema Estrela

É uma tabela fato, rodeada por dimensões, onde a tabela fato tera metricas ligados dimensões com informações descritivas  

### Caracteristicas

#### Uma tabela de fatos central

Contem as metricas ou medidas quantitativas do negocio e as FK que referencia as tabelas dimensões. É onde os eventos de negocio são registrados
Exemplo:
- vendas, pedidos, cliques

#### Multiplas tabelas de dimensoes

Contem os atributos descritivos que fornecem o contexto para os fatos. Cada dimensão representa uma perspectiva de analise
Exemplo:
- tempo, produto, cliente, localização

#### Relacionamento um-para-muitos

Cada tabela de dimensão se relaciona com a tabela de fatos atraves de um relacionamento de chave primaria para chave estrangeira

#### Desnormalização das dimensões 

As tabelas de dimensões elas podem conter informações redundantes colocadas de proposito, para otimizar as consultas, evitando `JOIN` complexos
