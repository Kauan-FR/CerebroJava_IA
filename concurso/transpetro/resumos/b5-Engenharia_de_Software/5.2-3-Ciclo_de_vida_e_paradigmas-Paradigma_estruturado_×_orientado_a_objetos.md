## O que é Ciclo de Vida 

Jornada do software desde de a ideia inicial ate a manutenção continua

## Fases

- Planejamento e Levantamento de Requisitos => Descobrir o problema do usuario e definir objetivos e escopo
- Analise e Design => Definição de arquitetura, ferramentas, banco de dados e fluxos e funcionamento
- Implementação => Escrita do codigo seguindo as diretrizes definidas nas etapas anteriores
- Testes e Validação => Etapa crucial para garantir qualidade, segurança e consistencia, ultilizando testes unitarios, de integração e end-to-end
- Deploy, Entrega e Manutenção => Cliclo continuo de colocar no ar, evoluir, otimizar e corrigir problemas

## O que é paradigma

Maneiras diferentes de um programa resolver um problema

## Principais Paradigmas

- Abordagem imperativa
	- Paradigma procedural
	- Paradigma Orientado a Objeto
	- Paradigma Estruturado

- Abordagem declarativa
	- Paradigma Lógic
	- Paradigma funcional
