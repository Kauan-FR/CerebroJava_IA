## O que é Gerenciamento de Requisitos

Busca gerenciar as necessidades abstratas das pessoas, planejando atividades, atribuindo responsabilidades e avalie as entregas

## Tarefas

1. Manter em um repositorio
2. Priorizar requisitos
3. Encontrar o requisito
4. Avaliar mudanças
5. Aprovar requisitos

## O que é Levantamento de Requisitos

É uma conversa com o cliente onde iremos saber o que ele quer que seja desenvolvido e o que ele quer que contenha nesse desenvolvimento

## O que é Analista de requisitos

Responsavel por atuar com analise de requisitos, sejam eles funcionais, não funcionais, de usuario e dos clientes. Devem tambem realizar as especificações funcionais para o desenvilvimenbto de seftware
