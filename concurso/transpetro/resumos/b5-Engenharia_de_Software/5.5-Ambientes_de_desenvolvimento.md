## O que é

Anbiente o qual o dev se sente avomtade para desenvolver, errar, repetir e desenvolver livrimente sem seguir nenhum tipo de regra

- Desenvolvomento => Ambiente o qual o dev se sente a vontande para criar
- Stag => Encena o ambiente de produção
- Produção => O ambiente não pode ter erros, gargalos e roda com dados reais
